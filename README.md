# Run locally: INtayon - Ilocos Norte Chatbot

This repository contains everything you need to run the INtayon chatbot locally — no external AI API or provider is required for the default rule-based behavior.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. (Optional) If you want to integrate a remote AI provider, add it to your app and set any required environment variable in `.env.local`. By default, this version uses local rule-based responses — no API key needed.
3. Run the app:
   `npm run dev`
